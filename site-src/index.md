# Economie

Long-form, data-driven analyses of economies, built entirely from
public statistics — Eurostat, the World Bank, the ECB, the IMF, the
BIS, the IEA and others. Every chart is generated by code from a
published dataset, and every figure in the text can be traced back to
its source.

*The Romania, Greece and China reports were updated in October 2026
with data to 2025. The Romanian IT report will follow once Eurostat
publishes Romania's 2025 sector accounts.*

## How these reports are made

Each report is backed by a set of Python scripts that download the
data from the original publisher, save it as CSV files with the source
and retrieval date recorded in each file, and draw the charts. The text
is then checked figure by figure against those files. See
[About](about.md) for the method and its limits.
