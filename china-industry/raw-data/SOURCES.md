# Sources

Every chart in this project is built from a CSV in this folder. Each CSV
starts with a `# source:` / `# url:` / `# retrieved:` comment header that
documents where the data came from. This file is the project-wide index
of those CSVs.

**Conventions**

- Pandas reads these CSVs with `read_csv(..., comment="#")` to ignore the
  header lines.
- Multiple `# url:` lines mean the series was compiled from several
  publications (e.g. a yearly series from successive annual press
  releases).
- "Free" = publicly downloadable PDF / web page / data API without
  registration or payment.
- "Paywalled" sources are used only when the headline figures are
  separately republished in free trade press; both URLs are then in the
  CSV header.

**Refreshing data**

- World Bank-sourced CSVs (chapters 01 and 02) are regenerated by
  `python3 00_fetch_world_bank.py`. The fetch uses the `wbgapi` Python
  package against `https://api.worldbank.org/`.
- Other CSVs (chapters 03–11) are hand-compiled from the cited public
  reports. They are updated by editing the CSV directly; the chart
  scripts re-read on each run.
